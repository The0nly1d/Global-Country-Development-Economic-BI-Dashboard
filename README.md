# Global Country Development & Economic Performance BI Dashboard

**Role:** BI & Data Analyst

## 📌 System Scope
Designed and developed an interactive multi-page Power BI analytical dashboard analyzing socio-economic, health, demographic, and trade indicators across **195 countries** to support international policy and investment decision-making.

## 🛠️ Technical Implementation
- Cleaned and standardized raw datasets using **Power Query**.
- Structured a normalized **Star Schema** data model.
- Engineered organized **DAX** measure folders covering core KPIs, dynamic titles, conditional formatting, trade balance, and `RANKX` country standings alongside calculated classification columns.

## 📊 Interactive Dashboards & UI
- Engineered **3 core analytical views** featuring:
  - Custom left-hand navigation panel
  - Global multi-tier slicers
  - Interactive maps and scatter plots
  - Cross-page Drill-through
  - Custom hover Tooltips

## 🧩 Tech Stack
- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Star Schema Data Modeling**
- **Drill-through & Custom Tooltips**
- **Data Storytelling**
